## Differential test scope and limitations

The committed `jpeg_differential_audit.py` is a bounded integer PPC interpreter
and deterministic test generator. It reads the locally available source/original
ELF objects and does not distribute original executable bytes. Capstone and
pyelftools are required. Run it from the repository root after building the
three objects; do not run Python with assertions disabled.

- 9,456 paired calls across all 28 functions, seed 449529
- Normal and edge converters: scales 1, 2, 4, 8; multiple MCU origins; both
  edge-dimension branches; zero, partial and full extents; constant and random
  luminance/chroma bytes, including negative signed chroma and clipping
- Setters: all 256 component selectors and four supported IDCT sizes;
  randomized 16-bit image dimensions; return values, converter identities and
  non-stack side effects compared
- IDCT: all row extents 1..8 and column-mode representatives 1, 2, 3, 8;
  DC-only, sparse and dense coefficients; positive/negative coefficients and
  clipping-boundary DC values; pitches 8, 16, 32
- Every non-stack byte is compared, including guard regions, along with setter
  return values. Stack pointer, LR and GPR14..GPR31 restoration are checked
- Full instruction-address coverage was reached for all 20 non-grayscale
  converter bodies and both IDCT functions. This does not mean exhaustive
  branch/path/input coverage. Four grayscale bodies retain 19 unvisited
  instructions each in saturation paths that follow an unsigned byte load;
  each setter has one unvisited negative-selector branch instruction
- Function address relocations are normalized to deterministic symbol tokens,
  with collision checks. Real linked addresses and integration are not tested
- Only the observed integer instruction subset is implemented. Unsupported
  instructions/relocations/callees fail closed. No FPU, exceptions, cache/MMIO,
  timing, alignment faults, XER behavior or complete condition-register model
- `memset` is modeled by its memory effects and ABI-permitted volatile-register
  clobbers; its actual library machine code is not executed
- Inputs are bounded samples. Invalid pointers, zero scale, arbitrary invalid
  IDCT descriptors, all 32-bit coefficient patterns, concurrency, real JPEG
  streams and other units are not covered
- This custom interpreter is itself test tooling rather than a formally verified
  CPU implementation. Official objdiff, ctxdiff and full-DOL checks remain the
  matching/integration authority

Exact run output is preserved in `jpeg-remainder-differential-results.txt`.
