## Expression audit

The explicit rename-only rule prevents the requested cast, constant, and helper substitutions in this round. These opportunities were inspected and left intact:

- `CHANSVmNewObject` compares `type` with `3UL`. String Splice and Blob Seek/Write/Fill paths pass integer `1` to `CHANSVmConvertObjectType`. The existing object-type enum provides names, but substitution would change expression tokens; `3UL` also has an explicit unsigned-long type.
- `CHANSVmGetEnumedType` assigns dense matrix indexes 0 through 5. These indexes are not interchangeable with every VM object type tag, so a blanket constant rename would misstate their role.
- `VmGetStrFromObjHdr` and `VmGetIntFromObjHdr` are functions, not macros. They add object/payload null checks. Replacing raw Date/Array payload accesses with them would change expressions and potentially control flow.
- Array element pointer arithmetic, `VmArrayJoinSub` payload casts, Blob size reads, and Image payload offsets can be examined in a separately authorized expression cleanup. This patch changes none of them.
- `charBuffer` is accessed in character formatting. Its old `pad0` name was false; the 8-byte array remains exactly where it was. `stringHeaderBuffer` remains a byte array and is not retyped or reordered.
- The unused module parameters are called `reserved`; no semantics beyond non-use are inferred. Both current manager calls pass 1.
- Array Slice reuses two variables for its start/end argument objects and destination/source elements. The dual-role names preserve both uses without splitting declarations.
