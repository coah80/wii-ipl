Compared the scan with an independent rg enumeration and the historical
inventory. Reviewed live instruction bodies, including all original rows whose
old evidence only named an external SDK file. Public ogws runtime, startup and
NW4R arithmetic sources were fetched on 2026-10-05 for the references in docs.
The decoder classification uses the task's stated original-family convention:
ASH/ASR additionally use lis @h/ori @l for work and manual stmw frames; SZS keeps
the return length in r0 through its stackless byte-copy pipeline; Rvl_decode
branches directly into the decoder entry points.

The checker masks comments and strings, distinguishes declarations from bodies,
associates inline blocks with their owning function, includes nofralloc,
reads the existing UTF-16 sources, and checks configured assembly paths without
executing configure.py. Ambiguous function names or unsupported assembly syntax
fail inspection. Standalone assembly uses exported/typed function labels and
.fn/glabel entries; opaque includes/macros require inspection before it can pass.
