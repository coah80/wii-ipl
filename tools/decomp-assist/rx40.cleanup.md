## Rejected edits and scope limits

Trials 3 and 4 initially used the wrong animation enum value. The build caught
the changed instructions; trials 8 and 9 used the verified `ANIM_TYPE_BACKWARD`
value and passed. Trial 6 used an unavailable WPAD name; trial 10 used the
header's `WPAD_LIB_STATUS_0`. These three failures were mapping mistakes, not
proof that the expressions were load-bearing.

The other rejected cleanup candidates changed object bytes:

- `TextBalloon::calc`: replacing the fade-in switch with an if changed code,
  relocations, and symbol/string tables.
- `SDMemory::drawTransferTitles`: constructing each of the six GXColor values
  through its constructor changed code or `.strtab`. All six were isolated
  after the grouped trial failed; none was retained.
- `savedata::Manager::getAvailableInList` and `getNumValidChannel`: direct
  `mData.chanInfo` accesses changed instructions or relocations. The original
  offset expressions remain.
- `savedata::Manager::initManagerTask`: deriving the checksum address from `mData`
  changed instructions and relocations. The original address expression remains.
- `MemoryBase::is_fadein_enable`: using the existing child-wait predicate changed
  only `.strtab`, which still fails the whole-object requirement.
- `SDMemory::calc`: removing `== TRUE` from the scroller result changed `.text`.
- `CArGBAOdh::cdj_d_decompressLoop`: both integer-to-pointer work-buffer
  simplifications changed `.text`. The three corresponding compressor sites
  passed when tested individually and were retained.
- `MemoryBase::AnmButton::onCmdRecv`: replacing the unsigned command-range test
  with direct bounds changed code, relocations, and symbol/string tables.
- `iplSDChannelTitle_updateCopyPrepare`: spelling out the two transfer errors
  changed only `.strtab`; the unsigned range expression remains.

Remaining `unk_` member names are declared outside the assigned headers:
`FileInfo`, `CardState`, and `IconState` in `include/iplMemoryCardLib.h`, and
`Scroller::unk_0x3C` in `include/utility/iplScroller.h`. Their declarations and
uses remain unchanged. Unused reserved fields remain reserved. The save-data
`padding` array is cleared as serialized reserved storage, with no demonstrated
alternate meaning. The SDMemory double-to-float-to-integer conversions retain
an intermediate rounding step, so they are not redundant casts.

No source comments, assembly, declarations' order, or statement order were added
or rearranged. No configuration, symbol bounds, or other worker files changed.
