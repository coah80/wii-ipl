The replacement defines those arrays at the actual helper addresses and passes `TMCJpegTableInfo*` throughout. Quantization coefficients occupy four 256-byte tables. Two untouched words retain reserved names because this source never accesses them.

EXIF state fields are proven by the existing `work->pState = (TMCCJPEGDecState*)pInfo` assignment and calls into Setsize, converters, and restart handling. Their offsets equal the public decoder-state members. Four opaque public ranges and the public decoder-state debug layout remain constrained.
