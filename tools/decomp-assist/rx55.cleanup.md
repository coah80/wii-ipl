## Retained changes and rejected expressions

The 81 compiled trials retained 58 changes and reverted 23. The final diff changes 20 C files. Counts are 74 existing constants substituted, 113 explicit casts removed, 13 Boolean comparisons simplified, one forward scan changed to a do/while loop, one byte reinterpretation replaced by an existing member access, and four Boolean expressions stripped of redundant grouping. The member-access change accounts for one of the 113 removed casts. Work access now uses typed pointers or `ZI_WORK`; the duplicate `WORKP` macro and its 15 uses are gone.

Trials 44 and 45 preserve code/data scores but change only `.strtab`, through the compiler's anonymous exception-symbol numbering. Trial 65 also changes metadata only. Trial 80 preserves instruction bytes but changes object metadata. All remain reverted because this round requires complete object equality, including metadata.

The retained do/while scan removes the `body` and `down_start` labels without changing any object byte. The preceding-row loop, pinyin dispatch, key-selection loop, graph scan, Unicode range dispatch, and syllable exit rewrites were rejected. Existing shared failure paths remain ordinary C gotos.

The Korean record-field rewrites change address arithmetic or register operands. The current `offsetof` expressions are retained. `rx53.attempts.md` independently records the operand-order constraint on these accesses. The failed removal of the duplicate `packedCodes` assignment and the scalar casts in `Zi8ChangeCharCase` and `Zi8getKeyLayout` confirms those expressions affect code generation.

Four touched candidate-dispatch expressions retain their evaluation order while dropping redundant parentheses. Their object remains byte-identical.

The untouched permitted files are `eztx.c`, `zi8copy.c`, `zi8getc.c`, `zi8ver.c`, `zi8ZHuwd.c`, and `zierror.c`. Their remaining pointer conversions cross actual types or encode ABI/data representations; remaining numeric values lack matching named constants. No shared header or excluded source changed.

No owned function is non-matching. The expression-cleanup contract supersedes the generic matching-round requirement for increased exact counts. The 99 functions in touched units must stay 99/99, with 61,424 code bytes and 4,436 data bytes unchanged.
