# rx56 integrity audit

Baseline: `9d225c150d2dd75ba0ee7d53ed581f39da07433d`; branch `agent/w1005/rx56`; Wii Menu 4.3U. The worktree was clean and fetched origin/main matched HEAD at the start.

The retained cleanups preserve every complete object byte. The tree still contains compiler-steering constructs and eleven assembly placeholders. A claim of fully decompiled, readable source without matching tricks is not supported.

## Verification

The final clean, non-quick [gate run](rx56.gate.txt) ends in `GATE PASS`: zero baseline regressions, zero added forbidden patterns, zero readability warnings, and a successful full 4.3U build.

The separate [validation record](rx56.validation.json) compares the fresh baseline against the final clean build. It checks all 1027 source objects and all 1027 extracted target objects as whole files, all unit/function/section objdiff measures, every protected source hash, pools for every touched unit, and the DOL.

- Changed source units: 36; protected source files checked: 260.
- Touched instruction-exact functions: 988 -> 988, of 994.
- Touched objdiff code: 313864 -> 313864 bytes; data: 131068 -> 131068 bytes.
- Whole-tree code: 2824760 -> 2824760 bytes; data: 1832576 -> 1832576 bytes; exact functions: 12485 -> 12485; fuzzy: 99.820076% -> 99.820076%.
- DOL SHA1: `26116613f624061ba99c8d1a299aaa6efa85670d`.
- `ninja -C . progress build/43U/report.json build/43U/ok`: passed.
- Focused ctxdiff: ATERMApplyScanSecuritySettings 124/124 instructions, diffs 0; VFiPFFILE_p_fopen (containing the corrected file-creation helper) 350/350 instructions, diffs 0.
- `check_asm_inventory.py`: `ASM INVENTORY FAIL`, unchanged 173 assembly functions / 175 bodies, 162 ORIGINAL and 11 PLACEHOLDER.
- `check_decomp_complete.py`: `DECOMPLETE_FAIL`; 94.31032% code matched, 80.925865% code linked, 99.9941% data matched, 85.441246% data linked, 988/1027 units linked. This is the existing incomplete tree, not an audit regression.

The supplied gate/disassembly helper selects `.text` by name. Some objects have multiple sections with that name, so its instruction-exact counts can inspect the wrong section. The validation above follows each function symbol's section index, preserves conditional-branch CR selectors, and requires complete instruction bytes. Its before/after equality is also independently enforced by whole-object hashes. The gate transcript is saved verbatim; no shared tooling was edited.

## Coverage and evidence

Scanned 1958 C/C++/header files and 16569 function definitions across src/, libs/, and include/. Syntax-tree errors occurred in 722 files, including MWCC extensions, inactive branches and UTF-16 source; syntax candidates were supplemented by text searches, source review, assembly inventory and the latest 200 source-changing commits. This is not a proof of absence of all undefined behavior.

Ran 352 source trials: 274 compiled, 78 were rejected by the compiler. The [trial ledger](rx56.trials.tsv) records every trial, location, transformation, raw-byte decision, code/data cost, changed function percentages and pool result. A failed compile is not a measured byte cost. Many rejected cast candidates remove a required qualifier conversion and are not findings.

Line references for retained findings below use the baseline commit. Complete temporary sources, build logs and per-trial objdiff reports are in `/tmp/rx56/trials/<trial>/`; the committed ledger preserves the decisions and measurements if temporary files are removed. Rejected trials were restored and rebuilt immediately. No protected file, shared header, configuration, symbol boundary, target object, external gate script or baseline report was edited.

A cleanup with unchanged objdiff can still change ELF strings, debug information, symbol order or relocation identity. Those trials were restored under the explicit whole-object byte rule. They are useful zero-score-cost candidates for a parent decision, but are not claimed as accepted fixes.
